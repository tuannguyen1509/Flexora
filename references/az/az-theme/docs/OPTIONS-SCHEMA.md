# Options schema: current source baseline

Advanced Theme Options now stores new settings in `az_theme_options` as nested arrays. `az_get_option($path, $default)` supports dot notation. Legacy standalone options remain compatibility fallbacks and are not overwritten by Advanced saves. Registered section saves merge known keys into the existing section, preserving unknown nested keys.

## Child theme installation (2026-10-05)

| Store | Key | Contract |
| --- | --- | --- |
| transient | `az_child_theme_install_status` | Installation result code, TTL one week; cleared by nonce-protected dismissal. Does not control the active theme. |
| transient | `az_child_theme_install_prompt` | Previous manual-install prompt; cleared after automatic installation/manual retry/dismissal. |
| option | `az_child_parent_mods_migrated` | Boolean marker (1), non-autoloaded; new starter sets it after importing missing parent theme-mods and Additional CSS on first child activation. |
| option | `theme_mods_az-theme` | WordPress-owned parent Customizer settings; read as migration defaults, never overwritten by the installer. |
| option | `theme_mods_az-theme-child` | WordPress-owned child Customizer settings; only missing keys imported, excluding parent's CSS post ID. |

Additional CSS is copied through `wp_update_custom_css_post()` into a child-specific `custom_css` post only if none exists. `az_theme_options` and existing child files are unchanged. See [CHILD-THEME.md](CHILD-THEME.md).

## Status

- **Active**: current source references or defines the key; this does not prove a stored value exists.
- **Legacy**: current separate option or theme_mod contract retained for compatibility (including az_ and az_).
- **Planned migration**: future mapping to az_theme_options; no automatic copying/deletion in STEP 00.
- **External**: WordPress/plugin-owned key; preserve owner contract.

The contact screen reads option -> theme_mod -> default and mirrors submitted values to theme_mod. Home settings UI was removed earlier but frontend reads remain. Missing UI does not mean a key is unused.
