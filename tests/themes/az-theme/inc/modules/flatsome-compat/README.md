# Tương thích Flatsome cũ

Module giữ cho nội dung cũ tiếp tục hoạt động sau khi chuyển sang AZ Theme.

Shortcode được hỗ trợ:

- `[section]...[/section]`
- `[row]...[/row]`
- `[col span="..."]...[/col]`
- `[ux_sidebar id="shop-sidebar"]`
- `[ux_products columns="..." cat="..."]`
- `[blog_posts style="shade" type="row" columns="1" cat="1" posts="1"]`

Module chỉ đăng ký shortcode chưa tồn tại để không ghi đè Flatsome hoặc plugin khác. Có thể bật/tắt tại **AZ Theme → Advanced → Tương thích**.
